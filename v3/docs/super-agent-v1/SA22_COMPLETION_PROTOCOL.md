## 证据与计时

受控长期运行使用专属 PG、原 Engine 持锁连接、原飞书适配器／入站／通知／Dispatcher、
真实 CAS 和原 IsolatedExecutionBroker。平台为明确合成的本地 HTTP 端点，模型关闭，
项目进程无网络、无宿主凭据；不对 Bot 群发送探测，不启动付费轮询。
周期性新增合成事件和隔离命令作为负载；这不是重复运行历史 pytest 用例。
记录每次原始事件、Run／Action、CAS／代码树／命令回执及延迟，单独记录空闲时段。
受控平台成功不能升级真实平台或真实编码门。

每 60 秒采样，正常事件每 300 秒一次，独立沙箱每 1800 秒一次；仅当前试验拥有的
容器／目录可操作。运行至少 259200 秒，使用单调时钟和 UTC 双重记录；采样间隔超过
180 秒、进程重启、机器挂起、时钟倒退或源码变化形成明确中断，不拼接成连续通过。
保留所有段和失败，达到时长还须检查原始链、错误、故障覆盖及资源／账本一致性。
受控 72h 结束前不开始正式真实 72h 计时；现有 Bot 使用只作观察。≥5 工作日必须真实
经过并有本人反馈。定时器结束不能自动审批整卡，缺故障／反馈／独立证据仍不通过。

真实进程故障检查在单独的短期资格检查中进行，避免误杀群机器人和主库。包含原
Controller SIGKILL 后从已提交输入恢复、实际 PG 隔离实例重启、沙箱／通知未知结果
不重发和 CAS 错误不伪成功。既有 SA21 故障证据可只读引用；缺项保持 NOT_RUN。
