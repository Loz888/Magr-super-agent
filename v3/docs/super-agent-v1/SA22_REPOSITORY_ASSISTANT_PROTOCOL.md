# SA22 仓库检索与对话承接补充协议

2026-11-16，按用户“请完成这部分任务”冻结本轮新检查范围。原模型接通协议、失败、
归档和费用记录保留；本补充不升级H12质量门、不启动SA23或发布。

目标：本人在Bot群直接问“记忆功能如何实现”，系统自动定位、检索并读取相关源码，
回答引用固定提交的路径／实际行号；“那就查看完再回答”等追问可承接当前获准话题。
不再要求用户先知道具体文件名。自动检索是有限工具循环，不声称通用理解全仓。

只读工具为列目录、词面代码搜索、按行读取文件。读取固定Git对象，仅白名单普通
文本文件；不读活动工作树、宿主任意路径、symlink、submodule或秘密文件，不联网
取链接，不运行仓库代码。问题中的仓库目录链接或已绑定本机目录仅作定位提示。
英文标识符／路径与中文概念词辅助首轮检索；模型可继续搜索、读取后续行，整理
跨文件说明。文件／扫描／字节／行数／轮数均有硬上限，越界或无命中明确反馈。
引用须落在实际读取的文件及行区间内，文件hash与commit属于证据；不接受伪造引用。

新增能力通过显式新profile启用，原固定上下文默认路径保留。不改变Engine/API/
Settings/schema／财务函数或已有0054，归Harness第48节确认的SA私有问答／通知范围。
读取前后、每次模型物理发送前和答案派发前都重新核对当前来源／身份／策略／仓库
及路径权限；仓库内容、历史回答和工具错误均为数据，不创造执行／付款／发布权。

每次模型调用继续走原reserve_call/settle_call及SA07共同USD2。工具本身不收费，
每题最多4次工具纠正及最终回答，共5次付费请求，未确认调用不重发、不退款。
保留原root call用于答案引用，子步骤使用唯一step_key；每步真实用量先结算。
中断／unknown不偷偷重放整个问题，不伪称完成；无事件不空转。

对话从原PG的已完成且已投递问答中选择，限同项目、同来源安装／会话／原生话题、
同一可信本人及当前可读期限，最多3轮。无原生话题的个人Bot群按相同本人／群内
的最近获准上下文承接，不将业务Task合并。每轮仍有独立Run、当前目标与费用。
正文／答案不复制到新持久库；历史在原输入和短期答案密文中按需读取，原Mandate
只存有界无正文引用及全部依赖。跨群、跨人、未来消息、过期／撤权／删除内容拒绝。
依赖传递为有界去重引用；派生答案也服从全部来源依赖，不能在原消息删除后继续发。
历史仅解释指代，编码必须由当前新请求明确授权，历史指令不能触发新编码。

新增登记只运行本轮新本地Git、真实PG、受控HTTP／Outbox与故障检查。覆盖自然语言
定位／跨文件整理、长文件后部读取、固定提交／路径隔离、引用、连续追问／重启、
上下文过期／删除／撤权和最终发送边界、多步计费／unknown／上限与无副作用。
初轮检查前固定源码及协议；修复只重跑实际失败节点／目标，原20项和历史通过不跑。
实际平台／模型效果需新消息验证，不能以受控检查代替；启用后记录真实费用、任务
和回执，原完整SA22六门／长期运行要求保持独立。
