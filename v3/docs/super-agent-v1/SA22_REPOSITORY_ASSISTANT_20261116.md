## 现在如何使用

在Bot群正常@MAGR助手，直接问“v3.5的记忆管理是如何做的？请查看源码后回答”。
收到回复后可继续@问“那它如何避免读取别人的记忆？”或“继续查看相关实现”。
本人无需先知道文件路径；指定路径、标识符或后续行号也可帮助精确定位。

系统先按问题做概念词／标识符检索并读实际代码片段，模型可再调用list_files、
search_code、read_file进行有限定位和阅读，最后整理回答。引用只接受实际读取
过的文件和行区间，发送正文附固定commit、路径与行号；编造引用不会发成代码结论。
只读工具没有Shell、任意宿主路径、联网抓链接或代码写入能力。

当前读取已绑定提交`efb09f4fedb35c4bc7f579dda0b7e64d2e3111be`的`v3/src`与README，
不跟随活动main／未提交文件。范围、UTF-8／普通文件、文件数／大小、扫描／片段／
行数均有限额。长文件可按行读取后部；越界、二进制、symlink和常见秘密文件名拒绝。
自然语言检索是概念词辅助词面搜索与模型工具循环，不声称泛化语义质量已通过。

每题最多4次工具请求和最终回答，共5次原账本模型调用。工具自身不收费，模型仍
按原价格和SA07共享余额预占／结算。部分结果未知或进程中断不自动重放整个问题。
模型若提议编码，仍必须由当前新消息的明确编码指令触发原隔离实验；历史指令
不能开工。原分支、推送、PR、合并和发布继续关闭，H12质量FAIL／MVP未放行保留。

## 对话范围及权限

最多承接最近3轮已投递问答，限同项目、来源安装、群／原生话题与同一可信本人。
个人Bot群无原生话题时采用同群本人最近获准上下文，业务Task仍各自独立，不合并。
对话仅在原可读期限内有效，当前正文TTL30分钟；过期后不能依赖此前聊天继续追问。

原输入、短期密文答案、Run／Mandate及原Action/Outbox仍为事实源；没有新增会话
数据库、财务账本、schema或HTTP接口。Mandate只存有界无正文引用及最多16个传递
依赖，历史正文按需读取。重启从原PG和原私有短期密钥重建，不靠进程里的聊天缓存。

读取前后、每次模型物理发送前、输出存储和答案派发前重新核对当前来源／角色／
policy／仓库路径与全部历史来源。历史删除、过期或撤权也会阻止派生答案继续发出。
源码、工具输出与历史回答均为数据，不能产生新的执行、付款或通知权限。
模型用量先真实结算，格式／引用失败也不退还调用；unknown保持占款且同一步不重发。
