# ADR SAV1-22：本人本机试用，不配置云服务器

状态：ACCEPTED FOR LOCAL PILOT，2026-11-17。

本人明确回复：“没有云服务器，就在本机运行吧，云服务器暂时不考虑”。本轮保持
本机／WSL 布局，不租云主机、不购买资源、不开放公网管理入口。关闭客户端与关闭
宿主机器分别记录；原 ACCEPTANCE E19 的云端关机后继续暂缓，标 NOT_RUN_USER_DEFERRED。
本机在线成绩只代表本机试用，不提升为 Always-on／云端运行通过。

受控 72h、后续真实渠道 72h、至少 5 个工作日本人反馈、独立持出、10 个真实任务及
原共享 USD2 门槛继续有效。WSL、Docker 或宿主休眠／停机会使连续段中断；保留旧段，
不把未观测时长或多个短段相加冒充连续 72h。日历等待不增加模型调用。

本决定不启动 SA23，不改变 H12 原质量 FAIL、发布关闭及原业务写者／费用边界。
最终报告须同时列本机范围的结果与原完整系统尚未覆盖的门，不能把暂缓写为 PASS。
